## Board Analysis

## Working Principle
! This is pure speculation, we still need to figure out a few things:

### Switches
The switches are read through multplexing using the lines S1-5 as Outputs and KD0-2 as Inputs.
To figure out which switch is pressed, pull S1 high, read KD0-3, set S1 log, set S2 high, read KD0-3, set S2 Low,...

So far so good. But at the same time S1-15 are also used to drive the display, so all that needs to work with quite some refresh rate. That should be measureable by probing G1 with an oscilloscope.

### Display
For the display, the G0-G11 lines are used to activate the respective Grid, whose value can then be set using the S1-15 lines.
