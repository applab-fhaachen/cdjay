# CDJ-800

## Introduction
The CDJ-800 MK2, unlike the CDJ-100, but like the 200, has a dedicated board with an own controller for the switches, jog dial etc. This means that we do not need to implement an own controller circuit, but can 'just' communicate with the interface board.

## Mainboard Connectors
The Mainboard has two connectors for the CD-Player. These are not relevant for our project. We could think of adding connectors just to not have them dangling around. 
- CN102 for the spindle motor
- CN101 towards CN1101
The MAIN ASSY has two connectors relevant for our endeavour. CN301 (CD53) to the SECB ASSY and CN701 (CN801) to the JACK ASSY.

### Power Supply

What we we need: and I think that all comes from external, so we don't need to generate anything. (See Page 20)
V+7M 
V+8A
V+3D
V+6B
V+5P

On the regulator board, there are two ICs: IC92 and IC91. 
IC91: Takes V+6B and delivers V+3D
IC92: Takes V+10B and delivers V+7A
